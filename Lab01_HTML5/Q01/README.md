**Question:** Create a basic HTML5 webpage that includes the <!DOCTYPE html>, <html>, <head>, <title>, and <body> tags along with a heading and a paragraph describing your favorite hobby.

## Run / view the answer
- 1. Open `index.html` in Chrome/Edge/Firefox (double-click it).

## Expected output
A browser page should display the requested HTML structure, form, table, layout, or interactive example. If JavaScript prompts or buttons are used, try the interaction; open **F12 → Console** to see console output.

## Answer

## Q1. Create a basic HTML5 webpage that includes the <!DOCTYPE html>, <html>, <head>, <title>, and <body> tags along with a heading and a paragraph describing your favorite hobby.

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My Hobby</title>
</head>
<body>
  <h1>My Favourite Hobby</h1>
  <p>I love playing cricket. It keeps me fit and teaches me teamwork.</p>
</body>
</html>
```
