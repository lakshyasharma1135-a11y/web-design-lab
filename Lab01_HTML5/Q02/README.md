## Answer

## Q2. Write an HTML document demonstrating the use of text formatting tags: bold (<b>/<strong>), italic (<i>/<em>), underline (<u>), and strikethrough (<del>).

```html
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Lab Sheet 1 - Q2</title>
</head>
<body>
<p><b>Bold</b> and <strong>strong (important)</strong></p>
<p><i>Italic</i> and <em>emphasised</em></p>
<p><u>Underlined</u> text</p>
<p><del>Strikethrough</del> text</p>
</body>
</html>
```
