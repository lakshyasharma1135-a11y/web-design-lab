## Expected output
A browser page should display the requested HTML structure, form, table, layout, or interactive example. If JavaScript prompts or buttons are used, try the interaction; open **F12 → Console** to see console output.

## Answer

## Q3. Design a webpage that showcases all six levels of heading tags (<h1> to <h6>) alongside paragraph tags to show text hierarchy and spacing.

```html
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Lab Sheet 1 - Q3</title>
</head>
<body>
<h1>Heading 1</h1><p>Paragraph under h1.</p>
<h2>Heading 2</h2><p>Paragraph under h2.</p>
<h3>Heading 3</h3><p>Paragraph under h3.</p>
<h4>Heading 4</h4><p>Paragraph under h4.</p>
<h5>Heading 5</h5><p>Paragraph under h5.</p>
<h6>Heading 6</h6><p>Paragraph under h6.</p>
</body>
</html>
```
