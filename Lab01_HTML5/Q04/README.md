**Question:** Create a webpage using the <blockquote>, <q>, and <cite> tags to display a famous quote and its author.

## Run / view the answer
- 1. Open `index.html` in Chrome/Edge/Firefox (double-click it).

## Expected output
A browser page should display the requested HTML structure, form, table, layout, or interactive example. If JavaScript prompts or buttons are used, try the interaction; open **F12 → Console** to see console output.

## Answer

## Q4. Create a webpage using the <blockquote>, <q>, and <cite> tags to display a famous quote and its author.

```html
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Lab Sheet 1 - Q4</title>
</head>
<body>
<blockquote>
  The best way to predict the future is to invent it.
  <br><cite>- Alan Kay</cite>
</blockquote>
<p>As Gandhi said, <q>Be the change you wish to see in the world.</q></p>
</body>
</html>
```
