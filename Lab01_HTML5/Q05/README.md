## Run / view the answer

## Expected output
A browser page should display the requested HTML structure, form, table, layout, or interactive example. If JavaScript prompts or buttons are used, try the interaction; open **F12 → Console** to see console output.

## Answer

## Q5. Build a simple recipe page that utilizes <hr/> to separate different sections and <br/> for line breaks within an address format.

```html
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Lab Sheet 1 - Q5</title>
</head>
<body>
<h1>Masala Chai</h1>
<hr/>
<h2>Ingredients</h2>
<p>Water, milk, tea leaves, ginger, sugar</p>
<hr/>
<h2>Method</h2>
<p>Boil water with ginger, add tea and milk, strain and serve.</p>
<hr/>
<address>
  Chai Corner<br/>
  12, Main Market<br/>
  Roorkee, Uttarakhand<br/>
  India
</address>
</body>
</html>
```
