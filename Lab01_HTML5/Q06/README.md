**Question:** Create a webpage containing an unordered list (<ul>) of your top five favorite movies.

## Run / view the answer
- 1. Open `index.html` in Chrome/Edge/Firefox (double-click it).

## Expected output
A browser page should display the requested HTML structure, form, table, layout, or interactive example. If JavaScript prompts or buttons are used, try the interaction; open **F12 → Console** to see console output.

## Answer

## Q6. Create a webpage containing an unordered list (<ul>) of your top five favorite movies.

```html
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Lab Sheet 1 - Q6</title>
</head>
<body>
<h2>Top 5 Movies</h2>
<ul>
  <li>3 Idiots</li>
  <li>Dangal</li>
  <li>Inception</li>
  <li>Interstellar</li>
  <li>The Dark Knight</li>
</ul>
</body>
</html>
```
