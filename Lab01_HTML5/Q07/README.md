## Answer

## Q7. Design a step-by-step instruction guide using an ordered list (<ol>) with numerical markers.

```html
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Lab Sheet 1 - Q7</title>
</head>
<body>
<h2>How to Make Tea</h2>
<ol>
  <li>Boil water in a pan.</li>
  <li>Add tea leaves and ginger.</li>
  <li>Pour in milk.</li>
  <li>Strain into a cup and serve.</li>
</ol>
</body>
</html>
```
