## Answer

## Q8. Create a glossary page for computer science terms using a description list (<dl>), description terms (<dt>), and description definitions (<dd>).

```html
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Lab Sheet 1 - Q8</title>
</head>
<body>
<dl>
  <dt>CPU</dt><dd>Central Processing Unit, the brain of the computer.</dd>
  <dt>RAM</dt><dd>Random Access Memory, temporary working memory.</dd>
  <dt>OS</dt><dd>Operating System, software that manages hardware.</dd>
</dl>
</body>
</html>
```
