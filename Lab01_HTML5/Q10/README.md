## Answer

## Q10. Create an HTML file containing an ordered list that uses Roman numerals (type="I") and lowercase letters (type="a").

```html
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Lab Sheet 1 - Q10</title>
</head>
<body>
<ol type="I">
  <li>Frontend
    <ol type="a"><li>HTML</li><li>CSS</li><li>JavaScript</li></ol>
  </li>
  <li>Backend
    <ol type="a"><li>PHP</li><li>Python</li></ol>
  </li>
</ol>
</body>
</html>
```
