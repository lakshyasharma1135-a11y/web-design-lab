# Lab: Lab Sheet 1: HTML5 — Q11

**Question:** Write an HTML snippet to insert an image into a webpage using the <img> tag with proper src and alt attributes.

## Run / view the answer
- 1. Open `index.html` in Chrome/Edge/Firefox (double-click it).

## Expected output
A browser page should display the requested HTML structure, form, table, layout, or interactive example. If JavaScript prompts or buttons are used, try the interaction; open **F12 → Console** to see console output.

## Answer

## Q11. Write an HTML snippet to insert an image into a webpage using the <img> tag with proper src and alt attributes.

```html
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Lab Sheet 1 - Q11</title>
</head>
<body>
<img src="images/campus.jpg" alt="University campus building">
</body>
</html>
```
