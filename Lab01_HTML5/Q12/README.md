# Lab: Lab Sheet 1: HTML5 — Q12

**Question:** Create a webpage featuring an image where you explicitly define the width and height attributes.

## Run / view the answer
- 1. Open `index.html` in Chrome/Edge/Firefox (double-click it).

## Expected output
A browser page should display the requested HTML structure, form, table, layout, or interactive example. If JavaScript prompts or buttons are used, try the interaction; open **F12 → Console** to see console output.

## Answer

## Q12. Create a webpage featuring an image where you explicitly define the width and height attributes.

```html
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Lab Sheet 1 - Q12</title>
</head>
<body>
<img src="images/campus.jpg" alt="Campus" width="400" height="250">
</body>
</html>
```
