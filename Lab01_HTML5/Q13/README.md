# Lab: Lab Sheet 1: HTML5 — Q13

**Question:** Design a webpage containing an image that, when clicked, redirects the user to an external website using an anchor tag (<a>).

## Run / view the answer
- 1. Open `index.html` in Chrome/Edge/Firefox (double-click it).

## Expected output
A browser page should display the requested HTML structure, form, table, layout, or interactive example. If JavaScript prompts or buttons are used, try the interaction; open **F12 → Console** to see console output.

## Answer

## Q13. Design a webpage containing an image that, when clicked, redirects the user to an external website using an anchor tag (<a>).

```html
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Lab Sheet 1 - Q13</title>
</head>
<body>
<a href="https://www.wikipedia.org" target="_blank" rel="noopener">
  <img src="images/logo.png" alt="Visit Wikipedia" width="150">
</a>
</body>
</html>
```
