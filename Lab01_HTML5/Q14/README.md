## Expected output
A browser page should display the requested HTML structure, form, table, layout, or interactive example. If JavaScript prompts or buttons are used, try the interaction; open **F12 → Console** to see console output.

## Answer

## Q14. Implement an image layout using the <figure> and <figcaption> tags to display a photograph with a descriptive caption.

```html
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Lab Sheet 1 - Q14</title>
</head>
<body>
<figure>
  <img src="images/taj.jpg" alt="Taj Mahal at sunrise" width="400">
  <figcaption>Fig 1: The Taj Mahal at sunrise, Agra.</figcaption>
</figure>
</body>
</html>
```
