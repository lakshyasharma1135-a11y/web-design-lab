## Expected output
A browser page should display the requested HTML structure, form, table, layout, or interactive example. If JavaScript prompts or buttons are used, try the interaction; open **F12 → Console** to see console output.

## Answer

## Q16. Create an HTML table (<table>) with 3 rows and 3 columns containing student information using <tr>, <th>, and <td> tags.

```html
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Lab Sheet 1 - Q16</title>
</head>
<body>
<table border="1" cellpadding="6">
  <tr><th>Roll No</th><th>Name</th><th>Course</th></tr>
  <tr><td>101</td><td>Amit</td><td>MCA</td></tr>
  <tr><td>102</td><td>Neha</td><td>MCA</td></tr>
</table>
</body>
</html>
```
