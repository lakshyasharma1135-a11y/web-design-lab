**Question:** Design a product price list table that includes a proper table <caption> and clear table headers (<th>).

## Run / view the answer
- 1. Open `index.html` in Chrome/Edge/Firefox (double-click it).

## Expected output
A browser page should display the requested HTML structure, form, table, layout, or interactive example. If JavaScript prompts or buttons are used, try the interaction; open **F12 → Console** to see console output.

## Answer

## Q17. Design a product price list table that includes a proper table <caption> and clear table headers (<th>).

```html
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Lab Sheet 1 - Q17</title>
</head>
<body>
<table border="1" cellpadding="6">
  <caption>Product Price List</caption>
  <tr><th>Product</th><th>Price (Rs.)</th></tr>
  <tr><td>Notebook</td><td>60</td></tr>
  <tr><td>Pen</td><td>10</td></tr>
  <tr><td>Bag</td><td>650</td></tr>
</table>
</body>
</html>
```
