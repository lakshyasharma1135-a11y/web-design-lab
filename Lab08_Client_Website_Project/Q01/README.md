## Q1. Draft a project specification and wireframe layout for a fictional client (e.g., local artisan bakery, eco-friendly cafe, or boutique fitness studio).

**Specification**

| Item | Detail |
|------|--------|
| Client | Crumb & Co., artisan bakery |
| Goal | Online presence, table bookings, customer trust |
| Audience | Local families, students, office workers (18-45), mostly mobile users |
| Pages | Home, Menu, About/Team, Booking, Contact |
| Features | Hero carousel, booking form, testimonials, Google Map, social links |
| Technology | HTML5, CSS3 (Grid and Flexbox), vanilla JavaScript |
| Constraints | Mobile-first, WCAG AA, page load under 3 seconds |
