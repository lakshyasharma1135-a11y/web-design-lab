## Q12. Verify mobile responsiveness across diverse device viewports using browser developer tools.

1. Open the site in Chrome and press `F12`, then `Ctrl + Shift + M` (Device Toolbar).
2. Test these viewports: iPhone SE (375px), iPhone 14 (390px), iPad (768px), laptop (1366px).
3. Verify: no horizontal scrolling, text is readable, buttons are at least 44px tall, images fit the screen, the menu does not break.
4. Take a screenshot for each device.
