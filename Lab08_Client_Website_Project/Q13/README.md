## Q13. Prepare a comprehensive design rationale document explaining color choices, typography, and target audience alignment.

1. **Overview:** client, goals and target audience.
2. **Colour choices:** cream background (warm, appetising), brown (trust, bakery feel), orange accent for call-to-action buttons. Contrast ratios checked.
3. **Typography:** Georgia headings plus Segoe UI/Arial body text, modular scale of about 1.25.
4. **Layout:** mobile-first, single column on phones, three-column grid on desktop, generous white space.
5. **Audience alignment:** most visitors use phones, so the site has large tap targets, a click-to-call phone number and a one-step booking form.
6. **Accessibility:** alt text, ARIA landmarks, keyboard focus styles, 4.5:1 contrast.
7. **Performance and SEO:** optimised images, minified files, meta tags, semantic HTML.
8. **Conclusion:** how the design meets the client goals.
